### 1.3 一句话

- **比以前的模型好**：四段数据上，管内巡检视角的画面还原都比 v1.0 交付模型高 3.5–10 dB，三个频段的细节还原度都更高，错位小一半以上；
  InPipe 的新模型（Y1）在 10-21 最好模型（X7）的基础上又在两组留出帧上全面变好；Pipe1 第一次有了留出帧评测，新模型比 v1.0 高 10 dB。
- **比现有方法（3DGS、2DGS）好的地方是"离开训练视角"和"几何"**：训练视角附近大家差不多（InPipe 上 3DGS 的近处细节甚至更好），
  但离开训练视角 10 cm 时，本项目在四段数据上都比其中较好的那个高 3–7 dB，错位小 1.5–3 倍（concrete_2、实验室管）到 6–20 倍（InPipe、Pipe1）；渲染深度误差 0.6–1.8 %，现有方法 6–85 %。管道视频几乎只沿管轴前进，这种"只在训练视角对"的解特别容易出现，几何锚定是决定性的。
- **查看器里的网格**：InPipe 和 Pipe1 现在都有干净、连续、可直接打开的 OBJ（第 4、5 节）；Pipe1 的比 v1.0 高 3.9 dB；InPipe 的几何正确但画面 PSNR 仍低于 B（两种光源，剩余问题 1）。
- **没成功的**（如实记录）：不透明面元（Y4，回退）、位姿精修（整段留出变差，只作选项）、InPipe 烘焙的 PSNR 没追上 B；3DGS-MCMC 在默认参数下发散、2DGS 在实验室管 A 上两个种子都数值发散。

## 2. 对比方法与评测协议

### 2.1 量尺（与 docs/10 相同，不改）

量尺 v2（docs/10 第 2.2 节）：每段数据 44 张序列内留出帧 + 两段 10 cm 的"整段留出"帧（训练时拿掉）；所有模型在**同一批像素**（B 的掩码）上评分；
PSNR、错位 px、低频残差，加三个频段的细节还原度 `fid`（1.0 = 和无噪声画面一致；参照"对齐后的下一帧"是带噪声的真实画面能达到的水平）。
LPIPS 只在 InPipe（数字相机、噪声小）上有意义；Sheffield 模拟视频上它主要量噪声（docs/10 2.1）。

### 2.2 对比的现有方法（同一批训练帧、同一位姿、同一画布、同一初始点）

| 方法 | 出处 | 本项目里的实现 |
|---|---|---|
| OpenMVS 稠密 + 网格 + 贴图（× 灯光图 = B） | 传统 MVS 流程（OpenMVS 2.4） | v1.0 交付模型；B = 它 × 固定在画面上的灯光图（已经比原始贴图好 4 dB） |
| LiDAR 高度场 + 逐像素贴图（InPipe 的 B） | 本项目 v1.0（R3 + R4） | 同上 |
| 3DGS | Kerbl et al., SIGGRAPH 2023 | gsplat 1.6 DefaultStrategy（分裂 / 克隆 / 剪枝，15k 次停）、SH 每 1000 次升一阶、0.8 L1 + 0.2 D-SSIM、3 万次 |
| 3DGS-MCMC | Kheradmand et al., NeurIPS 2024 | gsplat MCMCStrategy（重定位 + 噪声，高斯数 = 初始点数）、不透明度 / 尺度正则 0.01 |
| 2DGS | Huang et al., SIGGRAPH 2024 | gsplat rasterization_2dgs、按 2DGS 梯度致密化、法向一致 0.05（7k 起）、深度畸变 0.01（3k 起） |
| 本项目 G0-A / X7（10-21 的最好模型） | docs/09、docs/10 | 高斯锚定在实测表面上（+ 车灯 / 环境光） |

三种高斯方法都从和我们**相同的 MVS 稠密点云**开始（比论文里的 SfM 稀疏点更有利于它们），用相同的训练帧、位姿、去畸变画布和迭代次数；
`train_gs.py --baseline 3dgs|mcmc|2dgs`。几何精度另算：渲染深度与实测几何（稠密点云）的中位相对误差。

### 2.3 Pipe1 的留出协议

Pipe1 抽帧时每一帧都进了模型（`--every 1`），没有"两帧之间"的帧可留。改用新视角合成的通行做法：
从注册帧里均匀取 44 张（不在两段 10 cm 整段留出内）**不参加高斯训练**，用它们自己的 SfM 位姿评分（`export_g0.py vision ... --lamp auto`）。
SfM、稠密点云、网格和 B 的贴图都见过这些帧——B 在这里是占便宜的；高斯模型没有。

## 3. Y1 InPipe：从视觉点云拟合干净的管壁（5.3 第 1 项，高）

**问题**（docs/10 X7、5.5）：InPipe 最好的模型锚定在视觉 OpenMVS 网格上——它是唯一与图像在毫米级自洽的几何——但深色光滑管壁上稠密点很少
（有纹理处每 10 cm 10–30 万点，光滑处只有 0.4–1.2 万点），网格有洞和飞片：渲染出暗斑 / 条纹（LPIPS 0.30 → 0.37），从管外看是一团漂浮斑块。
激光高度场 R3 干净，但半径小 13–15 %、圆心偏约 14 mm（X6）。

**做法**（`pipesplat/vision_surface.py`，WSL，约 1.5 分钟）：保留视觉几何，只加"它是一根管子"的先验——
1. **管轴**：从激光 R2 中心线出发，用视觉稠密点重新拟合：每 1 cm 一个节点，r(θ) = R + a cos θ + b sin θ + c cos 2θ + d sin 2θ（半径、圆心偏移、椭圆），
   全部点一次稀疏鲁棒最小二乘（Huber），沿管道二阶差分平滑（约 5 cm），每个 1 cm 段最多按 2000 点计权（稀疏段不被稠密段压倒）；
   中心线按 (a, b) 移过去再拟合，共 3 轮（圆心偏移 15.3 → 1.7 → 0.5 mm）。
2. **细节**：点到这个光滑模型的残差，2 mm × 1° 网格取中位数，和邻域差 3 mm 以上的格丢掉，归一化高斯平滑，按点数置信度 n / (n + 12) 淡出、限幅 ±8 mm：
   点多的地方保留接口、凹凸，点少的地方就是光滑的管壁——没有洞，没有飞片。
3. **开口**：管底开缝和两端取自 R3 激光网格在新坐标系里的占据（激光知道管子哪里是开的），所以新管壁只在真实开口处开口。
4. 锚定用的表面 `surface_vhf.npz` = 这根管子 + 视觉网格里**在管外**的三角形（管口外的标记板、开缝里看到的地面），后者保留它们原来的几何。

拟合出的半径：第一节 **109.4 mm**、第二节 **101.9 mm**——与两种独立测量一致（RealSense 立体深度 107.5 / 101.4，视觉 × 标记 110.0 / 100.5），
激光 R3 是 94.5 / 89.1。椭圆度中位 7.7 mm（激光也测到明显椭圆）。网格 25.3 万顶点、50.1 万三角形（中位 1.9 mm）。
图：`D:\pipe3d_gs\g0\inpipe_vision\vhf_radius.png`（展开的半径图）、`vhf_detail.png`（细节层）。

改动只有锚定表面这一项：模型配置与 X7 完全相同（视觉位姿、车灯 + 环境光、3 万次），`run_vhf`。

**目标**：InPipe（以及 Pipe1）也要有一份能在普通查看器里打开（OBJ + PNG）、几何正确、颜色来自原视频的网格。v1.0 里 InPipe 的网格是半径偏小 13–15 % 的 R3 + 错位 5 px 的 R4。

**做法**（`pipesplat/bake_vhf.py`，WSL，约 2 分钟）：Y1 的管子是 (u, θ) 上的高度场，贴图就是这个网格本身（0.5 mm 纹素），比 concrete_2 的 `bake_gs_tex.py` 简单；配方相同（docs/10 X8）：
每个训练位姿（整段留出帧不用）把纹素投进去，可见（深度 1.5 % + 2 mm 内）才取；"近"= 最清楚的视角（足迹权重 τ 1），"参考"= 前方 2.5 倍半径处的视角，贴图 = 近 × 模糊(参考) ÷ 模糊(近)。
评分与 X8 相同：精确三角形光栅化（`meshraster.py`）× 画面固定灯光图（B 的配方），同一批帧和像素。

过程中的三个发现（都在 InPipe Y1 上，序列内 / 整段留出 PSNR）：
1. **带车灯模型的"自身颜色"不能直接烘焙**：Y1 是车灯 + 环境光模型，高斯的颜色是"去掉车灯后"的颜色，它只有乘上车灯因子才像视频；直接烘焙出来是一圈圈漩涡（18.1 / 17.1 dB，错位 28 px）。
   → 新增 `--source video`（默认）：颜色直接取原始训练帧，可见性用管子自己的深度（精确三角形光栅化）。单帧往返检查：只用一帧烘焙、再从同一帧渲染，平均误差 0.006（1.5 个灰度级），几何链路无误。
2. **贴到模型自己的表面**（X8 的做法）：Y1 的渲染深度离拟合管壁只有中位 0.82 mm（p95 1.34 mm），移过去之后分数几乎不变（20.33 / 19.07 dB）。
3. **画面边缘的明暗被烙进贴图**：一个纹素最清楚的视角往往是它即将离开画面的那一帧（画面边缘车灯衰减和暗角最重），在别的视角里就成了一圈圈矩形台阶。
   → `--flat-iters 1`：先烘焙一次、学出这份贴图对应的"画面固定增益"（车灯 × 暗角），原始帧除以它再烘焙；`--edge-px 30`：离画面边缘 30 px 内的样本降权。
   20.33 → **20.95** dB，错位 4.0 → 2.7 px，LPIPS 0.465 → 0.393；整段留出 19.07 → 20.72 dB，细 / 中 / 粗 0.096 / 0.209 / 0.298 → **0.125 / 0.297 / 0.402**。
   再迭代一次 / 不用参考视角归一：±0.3 dB 以内，不再改善。

| InPipe（同一批帧和像素） | 序列内 PSNR | LPIPS | 错位 px | 细 / 中 / 粗 | 整段留出 PSNR | 错位 px | 细 / 中 / 粗 |
|---|---|---|---|---|---|---|---|
| B（v1.0：R3 + R4 × 灯光图） | **23.35** | **0.288** | 5.18 | 0.051 / 0.129 / 0.262 | **23.33** | 4.25 | 0.116 / 0.211 / 0.265 |

| 参照：Y1 高斯模型 | 30.77 | 0.342 | 0.80 | 0.580 / 0.774 / 0.881 | 26.87 | 2.03 | 0.492 / 0.693 / 0.821 |

**结论：部分采用。** InPipe 烘焙网格（`D:\pipe3d_gs\g0\inpipe_vision\run_bake_vhf_ms\obj\`：25.3 万顶点、50.1 万面、3220 × 1310 贴图）的**几何是对的**（半径 109 / 102 mm，与两种独立测量一致；R3 是 94.5 / 89.1），
颜色来自原视频，整段留出的结构比 B 准（三个频段都高）；但画面 PSNR 比 B 低 2.4 dB、低频残差约 B 的 2 倍：

管外视图（同一组虚拟相机，`D:\pipe3d_gs\review\outside_inpipe_y2.jpg`，每组三行 = 旧 R3 + R4 / X7 高斯 / Y2 烘焙网格）：Y2 是一根干净连续的管子，弯头和接口清楚，比旧 R3 明显粗（半径对了），没有 X7 那种漂浮斑块（脚本里的行标签沿用 concrete_2 的写法）。

## 6. 与现有方法对比（同一批帧、同一把尺子）

方法定义见 2.2 节。三种已发表的高斯方法用 gsplat 1.6 实现（`train_gs.py --baseline`），与本项目的模型**用同一批训练帧、同一位姿、同一去畸变画布、同一 MVS 稠密点云起步、同样 3 万次**，
在同一批留出帧、同一批像素上评分。下表由 `pipesplat/review/compare_methods.py` 从各 run 的 `summary_r2.json` 生成（第 1 节的总表同此）。

（表格见第 1 节；对比图：`D:\pipe3d_gs\review\cmp_methods_c2.jpg`、`cmp_methods_inpipe.jpg`：原视频 | B | 3DGS | 2DGS | 本项目，第一行序列内留出帧，后两行整段留出帧，每行下半是放大的近壁。）

读法：
1. **训练视角附近（序列内留出帧）各种高斯方法差不多**：concrete_2 上 3DGS 34.06、2DGS 34.33、本项目 34.42 dB，细频段都约 0.52；实验室管 A 上 3DGS 28.68 对本项目 28.78；
   InPipe 上 3DGS 的细频段（0.72）甚至比本项目（0.58）高——它没有被约束在管壁上，可以在两个相邻训练视角之间"记住"更多细节。
2. **离开训练视角 10 cm（整段留出）就分出高下**：concrete_2 上 3DGS / 2DGS 掉到 28.7 / 28.6 dB（比 B 还低 1.2 dB），本项目 33.7 dB；
   InPipe 上 3DGS / 2DGS 20.0 / 20.1 dB、错位 14.2 / 12.0 px，本项目 26.9 dB、错位 2.0 px；实验室管 A 上 3DGS 24.9 dB（比 B 只高 0.5），本项目 28.1；
   Pipe1（真实污水管、模拟视频噪声大）上现有方法连训练视角附近都不行：3DGS 序列内 27.6 dB、错位 8.8 px，2DGS 32.2 dB，整段留出 25.6 / 27.1 dB、错位 30 / 23 px，本项目 34.1 / 31.8 dB、错位 0.6 / 1.3 px。
   对比图 `cmp_methods_pipe1.jpg`：3DGS / 2DGS 是一片雾，管壁花纹、接口环和水流都没有。
   画面上（cmp_methods_*.jpg 的后两行）：3DGS / 2DGS 远处管段糊成一团、近壁出现漂浮的条带，管节接口的位置不对；本项目的接口环、远处端盖 / 标记板在原位。
3. **几何**：渲染深度对实测几何（MVS 稠密点）的中位相对误差，3DGS 12–85 %、2DGS 6–71 %，本项目 0.6–1.8 %——没有约束时高斯会用"看起来对"但位置不对的斑块拟合画面，
   这正是离开训练视角就崩的原因。管道视频的视角几乎只沿管轴前进（基线小、掠射角大），比一般场景更容易出现这种"只在训练视角对"的解，几何锚定在这里是决定性的。

   在这种米制、毫米级细节、视角单一的管道场景里不稳定。调它的超参数等于另做一个方法，本轮没有做；其余数据集上没有再跑（结论以 3DGS 和 2DGS 为准）。
   **2DGS 在实验室管 A 上数值发散**：两个随机种子（0、1）都在训练后段出现 NaN（训练 PSNR 掉到 6–7 dB），最终渲染全无效；同一实现在另外三段数据上正常。表中照实列出，不代表方法上限。
5. LPIPS 在 Sheffield / Pipe1（模拟视频、带噪）上主要量噪声，不作结论（docs/10 2.1）；在 InPipe 上本项目整段留出 0.386，好于 3DGS / 2DGS 的 0.457 / 0.454（序列内 0.342 对 0.358 / 0.362）。

   两种光源，"静态贴图 × 画面固定灯光图"表示不了。可做：烘焙时分离两种光（例如用 Y1 的车灯 + 环境光模型把每帧的车灯分量除掉，环境光单独烘一层），或查看器端带一个跟随相机的点光源。
   另外 InPipe 上高斯模型的 LPIPS（0.342）仍高于 B（0.288）：渲染比 R4 的逐像素贴图平滑。
2. **公制几何：Pipe1 的 SfM 尺度起伏（中）**：拟合管壁的半径沿管道 177–252 mm——SfM 局部尺度起伏（2 m 窗口 ±7–10 %，docs/10 3.2）。位姿与管壁同源，画面对齐不受影响，
   但这份网格的公制尺寸只在整体上对（按 435 mm 管径定尺）。可做：用画面计数器真值（Ground truth distances.csv）或"管径恒定"作约束分段修尺度，再重拟合管壁。
3. **高斯模型从管外看仍是斑点（中，已绕开）**：不透明面元（Y4）没解决；从管外看请用烘焙网格（concrete_2 X8b、InPipe Y2、Pipe1 Y3 烘焙），高斯模型只用于管内视角。
   烘焙网格的细节约为高斯模型的一半（静态贴图表示不了随车灯变化的起伏明暗，docs/10 X8）。
4. **细节上限（中）**：concrete_2 / 实验室管 / InPipe / Pipe1 细频段还原度 0.52–0.63，离无噪声的 1.0 还远；InPipe 上无约束的 3DGS 在训练视角附近细频段更高（0.72 对 0.58）——
   锚定用一点近处细节换来了离开训练视角不崩。可做：锚定面元 + 少量不锚定的残差高斯（只在训练视角附近允许），或 InPipe 改 1280×720 全分辨率（仍是 640×360，M1）。
5. **对比的范围（低）**：3DGS / 2DGS 用的是 gsplat 的实现、同一稠密点起步、同一训练设置，不是原作者代码和各自调好的超参数；3DGS-MCMC 在默认参数下训练发散、2DGS 在实验室管 A 上数值发散（见第 6 节），
   这两格不代表方法的上限。结论"离开训练视角 10 cm 时本项目好得多、几何误差小一个量级"在其余所有格子里成立。
6. **评测（低）**：Sheffield / 实验室管 / InPipe 的序列内留出帧用的是插值位姿（concrete_2 约 0.35 px 误差，对所有方法相同）；Pipe1 的留出帧是注册帧（自身 SfM 位姿），B 的贴图见过它们；
   LPIPS 在模拟视频上不可用（docs/10 2.1）。
7. **其它（低）**：Pipe1 画面四角约 11 % 在单 k1 畸变模型范围外；concrete_2 端盖高光（docs/10 X8b）；Sheffield 标定在检验视频上平均 −2.7 %；lampmap InPipe 渲染器主点偏 0.68 px（只影响 B）。
