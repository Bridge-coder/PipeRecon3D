## 2. 评测方法本身（量尺）

### 2.1 自检：不用任何模型，只把原视频帧本身处理一下，看量尺给几分

`pipesplat/diag_ruler.py`，在两段数据各自的 44 张序列内留出帧上（与 lampmap、docs/08–09 同一批帧、同一批像素），
把**原帧自己**做重采样 / 模糊 / 去噪 / 加噪后当作"渲染图"打分。结果 `D:\pipe3d_gs\review\ruler_*.json`。

| 原帧经过的处理 | concrete_2 PSNR / LPIPS / 细节能量比 hf_ratio | InPipe PSNR / LPIPS / hf_ratio |
|---|---|---|
| 训练画布往返（`train_gs.py` 去畸变画布 → 回到原始画面，两次双线性重采样） | 43.7 / **0.100** / **0.54** | （k1 = 0，无重采样） |
| 同上，画布中心对齐整像素 | 44.2 / 0.093 / 0.56 | — |
| 高斯模糊 σ = 0.5 / 0.8 / 1.2 px | 48.2 / 0.045 / 0.62；41.0 / 0.236 / 0.30；38.6 / 0.362 / 0.15 | 47.0 / 0.036 / 0.68；40.2 / 0.189 / 0.40；37.5 / 0.298 / 0.23 |
| **去噪**（OpenCV NLM，h = 5） | 38.2 / **0.379** / 0.29 | 37.5 / 0.298 / 0.71 |
| 加白噪声 σ = 3 / 6 灰度 | 38.7 / 0.096 / 1.21；33.0 / **0.373** / 1.71 | 38.6 / 0.034 / 1.17；32.7 / 0.125 / 1.66 |
| 视频下一帧 N（之前的参照） | 33.6 / 0.126 / 0.92 | 34.8 / 0.072 / 0.99 |
| （对照）docs/09 的 G0-A 高斯模型 | 34.4 / 0.379 / 0.15 | 27.3 / 0.319 / 0.23 |

读法：
1. **在 Sheffield 模拟视频上，LPIPS 主要在给"噪声像不像"打分。** 原帧去噪后（一张完美的无噪声画面能做到的最好情况）LPIPS 是 0.379，
   和 G0-A 模型完全一样；原帧加 σ = 6 的噪声也是 0.373。所以 docs/08–09 的"所有高斯模型的 LPIPS 都没有赢过 B（0.41）"
   不能说明模型不清晰——在这个量程里 LPIPS 分不出"清晰的无噪声画面"和"糊的画面"，反而偏爱带噪声颗粒的 B。
2. **hf_ratio（细节能量比）的分母包含噪声**：去噪后的原帧只有 0.29，所以"渲染细节能量只有视频的 14–35 %"大部分是噪声造成的错觉。
3. **训练流程本身就有可测的模糊**：去畸变画布往返一次（两次双线性插值、画布中心落在半像素上），什么都不学就损失约 46 % 的细节能量，LPIPS 0.10。
   这是可以修掉的（第 4 节 X3）。
4. InPipe 是数字相机，噪声小，LPIPS 在那里仍然有区分度：G0-A 的 0.32 相当于把原帧模糊 σ ≈ 1.2 px。

### 2.2 量尺 v2

`imgmetrics.ruler2` + `train_gs.py --ruler2`（训练结束时自动多算一遍，文件 `*_r2`），汇总 `python -I pipesplat/summarize_r2.py`。

- **所有模型在同一批像素上评分**：B 的掩码 ∩ 有效画面，不再按各模型自己的不透明度取像素（旧量尺 0.99 阈值下每个模型的像素不同，
  半透明的地方被直接剔除、不扣分；新量尺里盖不住的像素会因为变暗而扣分）。
- **细节分三个频段**：细 0.7–1.4 px、中 1.4–2.8 px、粗 2.8–5.6 px（高斯差分）。
  - `fid`（细节还原度）= 渲染与视频帧在该频段的相关 ÷ √（视频帧与"光流对齐后的下一帧"的相关）。
    下一帧拍的是同一处、噪声独立，后者就是噪声允许的上限，所以 `fid` 估计的是**和无噪声画面的相关**：1.0 = 细节全部在位。
  - `en`（细节能量）= 渲染在该频段的能量 ÷ 视频的**信号**能量（视频帧与对齐下一帧的互能量，噪声不计入）：1.0 = 和视频一样多的真实细节；< 1 偏糊；> 1 是多出来的假细节或噪声。
- 两条参照线：`Nal`（对齐后的下一帧：完美但带噪声的画面）、`D`（原帧去噪：从测试帧自己得来，`fid` 会大于 1，只用来标出 LPIPS 的噪声底）。
- PSNR、LPIPS、错位、低频残差照旧计算（与旧数字可比）。

（v2 下重新评分的结果见第 3 节）

## 4. 修复记录

每项只改一件事，在同一批帧上前后对比：序列内留出帧（44 张，表中取"段外"的中位数）和整段留出帧（行程 35 % / 65 % 处各 10 cm、训练时拿掉的帧）。

### X4 贴图模型 TX：实测几何不动，用原始帧学一张高分辨率贴图（H1）

为什么：交付物应该是"几何准确 + 贴图像原视频"的带纹理网格；现有 OpenMVS 贴图取自 CLAHE 帧、每面一张图（3.5 节），高斯模型又导不出网格贴图。
X2、X3 也说明换表示方式本身不解决模糊，所以先做一个结构最简单、可交付的模型，看它和高斯在同一把尺子上差多少。

做法（`pipesplat/train_tex.py`，导出 `pipesplat/export_tex_obj.py`）：
- 几何 = 实测表面（concrete_2：OpenMVS 网格；InPipe：R3 高度场网格），训练中**不动**；每帧用 gsplat 3DGUT 直接在原始畸变画面上画出表面的深度和平滑法向（不重采样图像）。
- 贴图 = 按管道展开的 (轴向 u, 角度 θ) 网格，0.5 mm × 0.5 mm（concrete_2：1895 × 9586 纹素）；封闭管末端的端盖另用一张 (y, z) 平面贴图。
  采样按每个像素在贴图上的覆盖大小做 mip 三线性插值（远处管壁不闪烁）。
- 颜色 = 贴图 × 车灯因子（与 `train_gs.py --lamp` 相同：固定在画面上的 M × cos / r²，灯位置可学）× 每帧增益 + 偏移；损失 0.8 L1 + 0.2 D-SSIM，对**原始帧**（不做 CLAHE）。
- 评分与高斯模型完全相同（量尺 v2，同一批帧和像素），文件 `summary_r2.json`，`summarize_r2.py` 把它和高斯模型列在一张表里。

### X4c 贴图模型：修正贴图的数值范围（实现错误）

### X8 把高斯模型 G0-A "烘焙"成网格贴图（5.3 节第 2 项，2026-10-21 下午，另一个会话）

目标：concrete_2 上一份**能在普通查看器里打开（OBJ + PNG）、颜色来自原始视频（不是 CLAHE）、清晰度接近 G0-A** 的带纹理网格。
做法：不再学贴图，而是把已经训练好的 G0-A 从训练视角渲染出来，投到网格贴图上。

做法（`pipesplat/bake_gs_tex.py`，网格 `pipesplat/review/dump_mesh.py` → `mesh.npz`，导出 `export_tex_obj.py --mesh`）：
1. **纹素 → 表面点**：贴图版式与 TX 相同（按管道展开的 (u, θ)，0.5 mm；端盖另用 (y, z) 平面贴图）。把网格的三角形在 (u, θ) 里光栅化，得到每个纹素在三角形上的三维点（就是查看器里这个纹素画在哪）。
2. **投影**：420 个训练位姿（整段留出帧的位姿不用），在训练画布上渲染 G0-A 的颜色和深度，把纹素投进去，取可见（深度一致）、G0-A 不透明（α ≥ 0.95）处的颜色；同时记下这个视角里一个**原始像素**在管壁上有多大（足迹，含 k1 在画布边缘约 2 倍的拉伸）。
3. **组合**：每个纹素两种加权平均——"近"：足迹最小的那些视角，权重 exp(−(足迹/最小足迹 − 1)/τ)；"参考"：相机前方 0.65 m 处的视角。
   贴图 = 近 × 模糊(参考) / 模糊(近)（贴图上 12 mm 高斯，按通道）：细节来自最清楚的视角，明暗来自同一距离的视角。

### 5.3 剩余问题（按严重程度）

（2026-10-23/24 的处理和结果见 [docs/11_质量提升与方法对比.md](11_质量提升与方法对比.md)：第 1、2、4、6 项已处理或部分处理，新的剩余问题在 docs/11 第 8 节。）

1. **InPipe（高）**：X7 的视觉网格在深色光滑管壁上有局部错误 / 空洞，渲染出几块暗斑和条纹（LPIPS 0.30 → 0.37）；整段留出仍有 3.3 px 错位。
   README 和 v1.0 Release 里 InPipe 的"最终模型"（R3 + R4）几何半径偏小、贴图错位 5 px，这两个交付物本身还没有更正（只在本文件记录）。
   可做：用激光 / 深度校正过尺度和半径的管轴作为先验去补视觉网格的空洞；InPipe 改用 1280×720 全分辨率（`export_g0.py inpipe --width 1280` 已支持）。
2. **网格贴图（高 → 中）**：没有一份既忠实于原视频、又能在普通查看器里直接看的网格贴图。TX 的问题在车灯模型（学到的灯位置不合物理）；可做：把高斯模型从多个视角"烘焙"到网格贴图，或给 TX 换更强的光照模型（随视角变化的少量参数）。
   **X8 已在 concrete_2 上做了烘焙**：颜色忠实、可在查看器里看、管外干净，但细节只有 G0-A 的一半左右——静态贴图表示不了跟着相机走的车灯照出的起伏明暗；端盖高光残留；实验室管 A / InPipe 未做。
   **X8b**：管壁上的小洞已补上（`run_bake_allwall\obj`）。端盖高光在每个视角里都落在端盖同一位置（相机沿管轴正对堵头），换视角去不掉；端盖段的误差主要是近场车灯照明和端盖处错误的网格，要先修那里的几何、再加镜面 / 近场光照。
   注意：`train_tex.py` 的圆片渲染器不适合给"贴在三角形上"的贴图评分（X8），网格贴图应加 `--mesh-raster`。
3. **细节上限（中）**：concrete_2 / 实验室管上细频段还原度 0.52–0.63，离无噪声的理想 1.0 还远；剩下的是亚像素配准误差（留出帧插值位姿约 0.35 px、网格起伏 2–3 mm）和视频噪声本身。
4. **真实污水管 Pipe1（高，本次未处理）**：管底水流处空洞和飞片、四角 11 % 画面没用上（单 k1 畸变模型）；每一帧都参与了建模，没有留出帧，无法用本量尺评分。
5. **评测（中）**：LPIPS 在模拟视频上不可用（原帧去噪 0.38–0.52）；量尺 v2 的 `fid` 依赖光流对齐下一帧，对齐误差会让它略偏乐观；序列内留出帧的位姿是插值的（concrete_2 约 0.35 px 误差）。
6. **其它（中 / 低）**：SfM 局部尺度起伏（Pipe1 ±10 %）；Sheffield 标定在检验视频上平均 −2.7 %；车灯模型学到的灯位置在 InPipe / TX 上不稳定；lampmap InPipe 渲染器主点偏 0.68 px（B 基线）。

### 5.5 补充：从管外看（2026-10-21 下午，应用户要求）

做法：新旧模型用**同一组虚拟相机**渲染 v1.0 `model_views` 版式的管外（方位 36°、仰角 13°）、剖开（55°、32°，去掉靠近观察者的一半）、侧视正投影（640 px/m）视图，
旧模型用原来的光栅化器（`pipesplat/review/outside_views.py`），高斯模型用 gsplat（`outside_views_gs.py`；只用不随视角变化的基础色，剔除 > 8 mm 的高斯，占 0.4–1.8 %），
拼图 `outside_compose.py`（新图亮度按旧图中位数对齐）。InPipe 的融合坐标系与视觉坐标系是同一个（视觉坐标轴 × 标记尺度），所以三段数据都能在同一相机下比。

| 数据 | 对比图 | 结论 |
|---|---|---|
| concrete_2 | `D:\pipe3d_gs\review\outside_concrete_2.jpg` | 新模型从管外看有斑点、毛边，剖开图里有透白的空洞；旧网格干净连续、接口清楚 |
| 实验室管 A | `D:\pipe3d_gs\review\outside_concrete_lab.jpg` | 新模型尚可但有斑点；剖开图两者接近，接口都清楚；旧网格更干净 |
| InPipe | `D:\pipe3d_gs\review\outside_inpipe.jpg` | **新模型（视觉几何）从管外看是一团漂浮的彩色斑块**（视觉稠密点云 / 网格的离群点和飞片全部暴露）；旧的激光高度场干净连续 |

原因：
1. 高斯模型只用管内、贴着管壁斜着看的画面训练过：锚定薄片的不透明度中位只有 0.14，斜看时很多片叠在一起才不透明，从管外正面看每条视线只穿过一两片 → 透白、斑点。
   显示时把薄片当不透明（`--opaque`，第三行）能补上空洞，但单片的颜色本来就是"叠起来才对"的分量，仍然满是斑点。
2. 管内视角下被管壁挡住、或恰好落在正确像素上的离群点和飞片，从管外全部暴露——InPipe 的视觉重建尤其多。

**这修正了第 5.1 节的说法**：那里的"最好的模型"指的是**管内视角（巡检视角）的画面还原**——那是量尺 v2 评测的内容，结论不变；
但**作为一个从外面看的三维模型**，新高斯模型不如旧网格，InPipe 的新模型尤其差。要两者兼得，需要把高斯模型的外观烘焙到干净的网格上（另一个会话正在做 concrete_2 的烘焙），
InPipe 还需要一份既干净（像激光高度场）又与图像对齐（像视觉几何）的表面，例如用 RealSense 深度修正过半径的激光高度场（X6b）再配准到视觉位姿。
