# 原始数据下载清单

本仓库不转发原始数据集。它们都有永久地址（DOI），按下表下载、核对 MD5 后放到 `config/paths.json` 指向的位置，即可复现全部结果。
文件列表和 MD5 取自各数据仓库的官方接口（figshare / Zenodo，2026-10-18 查询）。

| 文件 | 字节 | MD5 | 本项目用途 |
|---|---|---|---|
| `realsense_slam_20260312_172011.zip` | 10,110,969,751 | `ede7e0f718a783aaa742d38b2ebd97f4` | 融合 F1–F5 与最终模型 R1–R5；`scripts/run_inpipe.py --zip` 直接从 zip 流式提取，不需要解压（解压后 39 GB） |

下载（大文件，可用多连接下载脚本）：

```bash
python scripts/lidar/download_parallel.py https://zenodo.org/api/records/18615583/files/realsense_slam_20260312_172011.zip/content 10110969751 D:/fusion/raw/inpipe_172011/realsense_slam_20260312_172011.zip ede7e0f718a783aaa742d38b2ebd97f4
```
